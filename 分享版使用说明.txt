QSflow 分享版使用说明
=====================

接收方首次使用：
1. 将压缩包完整解压到本地磁盘，路径尽量不要过长。
2. 双击“启动_QSflow.bat”。
3. 启动器优先使用电脑中已有的兼容 Python 环境；如果没有，会创建项目专用 .venv 并安装依赖。
4. NVIDIA 用户需要训练加速时，再运行“安装_GPU_训练环境.bat”。普通标注和 CPU 推理不要求 CUDA。
5. 在软件中按 F1 可查看完整使用手册和快捷键。

分享版不会包含制作者的：
- 最近项目和模型路径
- API 配置或 API Key
- 数据集与 .avls 检查记录
- 虚拟环境、Python 缓存和运行日志

注意：
- 请勿只发送单个 BAT 或 app.py，必须发送整个 QSflow-portable 文件夹。
- 数据集、训练结果和模型由使用者自行保存；删除软件文件夹前请先备份这些内容。
- API 服务可能单独收费，ChatGPT Plus 套餐不等同于 OpenAI API 额度。
- QSflow 依赖 Ultralytics。个人学习、课程、研究、公开开源与商业/闭源分发的许可条件不同；公开或商业发布前请核对 https://www.ultralytics.com/license ，必要时咨询许可方。
